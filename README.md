# E-Commerce Store

A responsive e-commerce website developed as part of my Full Stack Development internship. The project focuses on creating a simple and user-friendly online shopping experience with essential e-commerce functionality.

## Features

- Browse and view products
- Product details page
- Add and remove products from the cart
- View and manage cart items
- User registration and login
- Responsive design for different screen sizes
- Interactive functionality using JavaScript
- Clean and simple user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub

## Project Structure

```text
E-Commerce-Store/
├── index.html
├── login.html
├── register.html
├── products.html
├── cart.html
├── style.css
├── script.js
```

## About the Project

This project was built to gain practical experience in frontend and full-stack web development. It helped me understand how different web pages, user interactions, and shopping cart features work together to create a complete e-commerce application.
